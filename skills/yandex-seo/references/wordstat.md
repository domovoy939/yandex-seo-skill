# Вордстат: семантика под Яндекс

Вордстат (wordstat.yandex.ru) — единственный открытый источник частотности запросов в Яндексе. Цифры показывают число **показов** выдачи за выбранный период (по умолчанию — последние 30 дней), а не число людей.

## Операторы

| Запрос | Что считает | Пример |
|---|---|---|
| `сайт на тильде` | «широкая» частотность: все запросы, где есть эти слова в любой форме и с любыми добавками | включает «заказать сайт на тильде под ключ недорого» |
| `"сайт на тильде"` | только запросы ровно из этих слов, без добавок (формы слов — любые) | «сайт на тильде», «сайты на тильде» |
| `!сайт !на !тильде` | фиксирует форму слова | без «сайты», «тильды» |
| `"!сайт !на !тильде"` | точная фраза, точные формы | самая честная цифра «ровно так и ищут» |
| `[тильда сайт]` | фиксирует порядок слов | не путать с «сайт тильда» |
| `+на` | учитывает предлог или союз, который иначе отбрасывается | `сайт +для застройщика` |
| `-бесплатно` | исключает слово | `создание сайта -бесплатно -курсы` |
| `(лендинг\|сайт) тильда` | группирует варианты | считает оба запроса сразу |

**Правило:** для оценки реального спроса смотри широкую частотность, чтобы найти хвосты, а для решения «делать ли страницу» — частотность в кавычках. Широкая цифра часто в 10–50 раз больше реальной.

## Регион и период
- Регион выбирается в фильтре. Для локального бизнеса всегда снимай **два столбца**: Россия и регион (например, «Самара и Самарская область»).
- Небольшие региональные цифры (меньше 10) часто округляются или показываются нулём. Не делай выводов по одному месяцу — смотри вкладку «Динамика».
- Записывай период и регион рядом с каждой цифрой. Без этого цифры нельзя сравнивать.
- Вордстат иногда показывает предупреждение «может работать нестабильно» или капчу. Капчи не проходить за пользователя: отметить «не открылся» и вернуться позже.

## Интент: кто ищет
Это главный навык. Большая частотность ничего не стоит, если ищут не ваши клиенты.

| Запрос | Частотность (пример) | Кто ищет на самом деле |
|---|---|---|
| сайт жк | ~127 000 | покупатели квартир: «официальный сайт ЖК N». Заказчиков сайта там почти нет |
| сайт для застройщика | ~300 | застройщики и маркетологи, которым нужен сайт — это заказчик |
| интернет-магазин для бренда | ~270 | покупатели ищут магазин конкретного бренда |
| сайт каталог оборудования | ~500 | покупатели ищут каталог конкретного поставщика |
| создание сайтов (регион Самара) | ~1 300 | заказчики — это спрос студии |

Как определить интент:
1. Открой левую колонку подзапросов. Если в ней названия брендов, ЖК, адреса, «официальный сайт» — ищут покупатели.
2. Если в ней «цена», «заказать», «под ключ», «стоимость», «недорого», «студия», «разработка» — ищут заказчики.
3. Проверь выдачу (см. `serp.md`): если в топе карточки конкретных компаний и агрегаторы покупателей — интент не ваш.

Маркеры коммерческого интента: купить, заказать, цена, стоимость, прайс, под ключ, недорого, доставка, в [городе], отзывы, рейтинг.
Маркеры информационного: как, что такое, своими руками, пошагово, примеры, бесплатно, скачать.

## Как собрать кластеры
1. Составь 10–20 «маркерных» запросов: услуга × тип × город (`сайт на тильде`, `лендинг на тильде`, `создание сайтов самара`).
2. Для каждого сними широкую частотность, частотность в кавычках, 5–10 крупных подзапросов слева и «похожие запросы» справа.
3. Выкинь чужой интент (покупатели, бесплатное, обучение — если не продаёшь обучение).
4. Сгруппируй: **один кластер = один интент = одна страница**. Если два запроса ведут на одинаковую выдачу (одни и те же сайты в топе) — это один кластер.
5. Для каждого кластера реши тип страницы по выдаче: посадочная услуги, статья, каталог, карточка в Картах.

## Формат таблицы для отчёта
| Кластер | Запросы (широкая / в кавычках, Россия / регион) | Интент | Тип страницы в выдаче | Наша страница | Приоритет |

## Типичные ошибки
- Брать широкую частотность за реальный спрос.
- Не разделять регионы: «веб-студия» по России и по Самаре — разные рынки.
- Строить страницу под запрос, который ищут покупатели (большие цифры, ноль заявок).
- Делать отдельные страницы под синонимы, которые Яндекс считает одним запросом (одна и та же выдача).
