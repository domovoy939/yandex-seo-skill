# Задание агенту в браузере: разбор выдачи Яндекса

---

Задание: разобрать выдачу Яндекса по запросам для [название бизнеса], [сайт], регион [город].

1. Открой Яндекс в окне инкогнито (или выйди из аккаунта), выставь регион **[город]** — проверь, что он показан в выдаче. Можно добавить к адресу поиска параметр `&lr=[код региона]` (Москва 213, Санкт-Петербург 2, Самара 51).
2. По каждому запросу из списка посмотри первые 10 **органических** результатов. Рекламу (пометки «Реклама», «Промо») не считай, но запиши, сколько рекламных блоков.
3. Для каждого результата запиши: сайт, тип (студия / фрилансер / агрегатор / статья / конструктор / справочник / карточка в Картах), оффер и цену, если видны на первом экране, и чем сильны (кейсы, калькулятор, гарантии, отзывы).
4. Отметь колдунщики: блок Карт, Яндекс Услуги, товарная галерея, видео, быстрый ответ.
5. Для 3–5 самых сильных конкурентов открой сайт и коротко опиши: цены, сроки, сколько кейсов, есть ли калькулятор или квиз, что написано в «что входит в цену».

Запросы:
- [запрос 1]
- [запрос 2]

Правила: капчи не проходить, никуда не писать и ничего не заполнять на чужих сайтах, не выдумывать — только то, что видно.

Отчёт одним сообщением:
1. Таблица по каждому запросу: топ-10 (сайт, тип, оффер/цена), число рекламных блоков, колдунщики.
2. Конкуренты: чем выигрывают.
3. Вывод: какой тип страницы ранжируется и что нужно сделать нам.
