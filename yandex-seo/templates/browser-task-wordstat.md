# Задание агенту в браузере: семантика в Вордстате

Скопируй, подставь значения в [квадратных скобках] и отдай агенту, который управляет браузером (например, Claude в Chrome).

---

Задание: собрать частотность запросов в Яндекс Вордстате для [название бизнеса], [сайт].

Кто мы: [чем занимается бизнес, 1–2 фразы]. Регион работы: [город / вся Россия].

Открой https://wordstat.yandex.ru. Если просит войти — войди в аккаунт, который уже открыт в браузере. Если показывает капчу — **не проходи её**, остановись и напиши «Вордстат не открылся, капча».

Для каждого запроса из списка:
1. Сними частотность за последний месяц по **России** и по региону **[регион]**: широкую (как есть) и точную (в кавычках, например `"сайт на тильде"`).
2. Перепиши 5 самых крупных подзапросов из левой колонки с цифрами.
3. Отметь, кто ищет: **заказчик** (в подзапросах «цена», «заказать», «под ключ», «стоимость») или **покупатель** (в подзапросах названия брендов, «официальный сайт», адреса).
4. Перепиши 3–5 интересных запросов из правой колонки «Похожие» — их тоже стоит проверить.

Запросы:
- [запрос 1]
- [запрос 2]
- …

Укажи период, который показывает Вордстат, и предупреждения вроде «может работать нестабильно».

Правила:
- Ничего не оплачивать, не менять настройки аккаунта.
- Не выдумывать цифры: если запрос не открылся — так и напиши.

Отчёт одним сообщением — таблицей:
| Запрос | Россия (широкая / точная) | [Регион] (широкая / точная) | Топ подзапросов | Кто ищет |
И отдельным списком — похожие запросы, которые стоит проверить.
