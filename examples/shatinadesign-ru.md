# Пример: shatinadesign.ru — запуск и SEO за два дня

Сайт студии веб-дизайна «Шатина студия» (Самара, работа по всей России) запустился 13.10.2026. Сайт необычный: «рабочий стол» на React + three.js, разделы открываются окнами. Ниже — что нашли и что исправили по шагам скила. Все цифры — из реальных замеров (PageSpeed Insights, Яндекс Вордстат, собственная проверка), даты — октябрь 2026.

## Техника: было → стало

| Проверка | Было (13.10) | Стало (14.10) |
|---|---|---|
| PageSpeed, главная, мобильная | 24 | **95** |
| LCP, мобильная | 4,9 с | 2,7 с |
| TBT, мобильная | 4 520 мс | 20 мс |
| CLS, мобильная | 0,273 | 0,013 |
| PageSpeed, главная, десктоп | 99 | 100 |
| Посадочная «лендинг на Tilda», мобильная | 89 | 100 |
| Внутренних ссылок на главной после загрузки JS | 2 | 14 |
| Несуществующий адрес | 200 + содержимое главной (мягкая 404) | 404 со своей страницей |
| Старый домен | заглушка 200 + noindex | 301 на новый домен, старые пути → те же пути |

### Что именно было и как исправили
- **P0. Главная «пустая» для поиска после выполнения JS.** Иконки разделов были кнопками с обработчиком клика. В исходном HTML ссылки были, но после гидрации React их не стало, и робот не видел связи главной с разделами («ссылающаяся страница: не найдено»). → Иконки стали `<a href="/razdel/">` с перехватом клика, плюс в DOM остался список всех разделов и посадочных.
- **P0. Мобильная скорость 24.** Основной поток занимал 3D-объект на WebGL (three.js), в PageSpeed он считался программно и съедал секунды. → three.js грузится после первой отрисовки; на телефоне — после первого касания; на программном WebGL — статичная картинка.
- **P1. CLS 0,273 от заголовка.** Шрифт подгружался с fonts.gstatic.com, и h1 прыгал. → Шрифты на своём сервере (woff2, кириллица), `preload`, фолбэк с `size-adjust`.
- **P1. Мягкая 404.** Сервер на любой адрес отдавал index.html. → `try_files $uri $uri/ =404` и своя 404 с `noindex`.
- **P1. Переезд домена.** Старый домен отдавал заглушку с кодом 200 — «Переезд сайта» в Вебмастере так не запустить. → 301 с главной и всех старых путей, демо клиентов оставлены как есть.
- **P2.** Укоротили title (93 → 49 символов) и description (216 → 155), `llms.txt` со ссылками, ключ IndexNow и отправка после каждого деплоя, PNG-логотип в разметке Organization, постер видео на посадочной в WebP (94 КБ → 24 КБ) с `fetchpriority="high"`.

## Семантика: Вордстат (Россия, 08.09–07.10.2026)

| Запрос | Частотность | Кто ищет | Решение |
|---|---|---|---|
| сайт жк | ~127 000 | покупатели квартир («официальный сайт ЖК …») | не наш спрос, страницу не делаем |
| сайт для застройщика | ~316 | застройщики и маркетологи | посадочная есть, усилить тарифами и кейсами |
| создание сайтов (регион Самара) | ~1 266 | заказчики | главный локальный спрос → Яндекс Бизнес первым делом |
| заказать сайт под ключ | ~733 | заказчики | страница цен + статья о стоимости |
| лендинг на тильде | ~631 | заказчики и те, кто делает сам | статья «сколько стоит лендинг на Tilda» |
| интернет-магазин для бренда | ~270 | покупатели конкретных брендов | для SEO не подходит, только для прямых продаж |

Вывод: самый большой «наш» спрос — локальный («создание сайтов» в Самаре), и по таким запросам сверху стоит блок Яндекс Карт. Застройщики почти не ищут подрядчика в поиске — к ним идут через прямые продажи и партнёров.

## Что осталось на момент примера
- Яндекс Вебмастер, Метрика и Бизнес были временно недоступны после сбоя — шаги в кабинетах перенесены в план.
- Один лишний прыжок редиректа: `http://www.` → `https://www.` → главное зеркало.
